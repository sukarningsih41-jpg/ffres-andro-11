FF AUTO RESOLUTION
Menurunkan resolusi layar HP otomatis saat Free Fire / Free Fire MAX dibuka,
dan mengembalikannya saat game ditutup. Butuh Shizuku.

BUILD: upload semua isi folder ini ke GitHub (termasuk .github/workflows/build.yml),
lalu tab Actions > Build APK > unduh artifact FFRes-apk.
Kalau sebelumnya sudah pasang FFRes, UNINSTALL dulu sebelum memasang yang baru.

PAKAI
1. Start Shizuku (Wireless debugging).
2. Buka aplikasi, izinkan Shizuku, pilih resolusi, tekan MULAI MODE OTOMATIS.
3. Buka Free Fire. Aplikasi boleh ditutup, pemantau jalan di notifikasi.

Vivo: Pengaturan > Baterai > Konsumsi daya latar belakang tinggi, izinkan aplikasi ini;
kunci aplikasi di recent apps agar tidak dimatikan sistem.
Darurat: tekan RESET, atau restart HP.
